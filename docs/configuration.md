# Configure 


#### Workflow Overview
###### A workflow is an automated process that can run one or more jobs. You can configure and set up a workflow in a repository to build, test, package, release, or deply a project on GitHub. You can define a workflow in `.yaml` and save the workflow in the `.github/workflows` directory in a repository.

A workflow runs when triggered mannually, at a scheduled time, or by an event in your repository.

You can have multiple workflows in your repository.
